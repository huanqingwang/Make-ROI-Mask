# Make-ROI-Mask
using python package nilearn to make ROI mask for fMRI analysis

In an fMRI analysis, sometime we need to extract the neural signal of a specific brain region (region-of-interest; ROI) for further analysis.  
Here, the notebook uses getting a dmpfc mask as an example, walking us through 3 different ways to get the ROI mask.
